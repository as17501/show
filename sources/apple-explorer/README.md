# 苹果里面有什么？

面向亲子演示的 TypeScript + Three.js 小项目。模型、果皮纹理、横截面纹理和种子都在本地用代码生成，不依赖模型下载、图片服务或 API。

## 运行

```bash
npm ci
npm run dev -- --port 5188
```

在浏览器中打开终端显示的地址。需要支持 WebGL 2 的浏览器。生产构建不会请求外部字体、纹理或模型。

```bash
npm run build       # TypeScript 严格检查 + Vite 打包，生成 dist/
npm run preview     # 预览生产构建
```

`dist/` 是静态网站产物，需要通过 HTTP 服务打开；不要直接双击其中的 HTML。

## 和孩子一起玩

1. **切开苹果**：刀沿苹果腰部横切，上下两半分开。
2. **上下分开**：拖动画布内操作区的滑块，连续调整间距。拖到 0 可以重新合拢；手动调节会暂停自动旋转。
3. **看横截面**：暂时隐藏上半部分，从上往下看下半部分，清楚观察中心的种子室和种子。
4. **看种子方向**：暂时隐去果肉、淡化外皮，观察同一组完整种子沿 Y 轴（果梗到果底）的排列。这是明确标注的透视示意，不是切面。
5. **果皮 / 果肉 / 种子**：点右侧卡片或模型上的标签查看说明。选择内部部位会自动打开完整苹果。
6. **拖动 / 缩放 / 自动旋转**：在立体观察模式里从不同角度看苹果。
7. **重来**：取消进行中的切开动画，重置模型和视角。

切开、间距滑块和三种视角集中在观察台底部，与模型分区显示，不遮挡模型；手机端知识卡片位于整个观察台下方。拖动模型用于旋转，拖动滑块用于调节间距；种子方向和横截面模式需切回「立体观察」后调节间距。

适配手机和平板；支持键盘按钮操作、方向键调整滑块、屏幕阅读器状态提示和系统减少动画偏好。真实刀具操作应由成年人完成。

## 教学边界

这是结构示意，不是医学、植物学扫描数据，也不是精确物理切割模拟。

- 预先构造了沿 `y = 0` 横切的上下两半，不支持任意切割平面。
- 用五瓣结构表示种子室，模型共定义 10 个唯一种子 ID；数量和理想化竖直姿态是本例设置，不表示所有苹果都完全一样。
- **已纠正旧版“平放且两面复制完整种子”的错误**：先构造一组长轴沿 Y 轴的完整种子，每颗网格再按 `y = 0` 真正裁成互补片段。上下对应片段共用同一个种子 ID，绝不是两套完整种子。
- 本例选择了经过种子的切割位置；切面显示棕色种皮边缘与浅色内芯，而非完整的棕色泪滴形。若切割没有经过某颗种子，该颗会留在一侧，裁切函数不会凭空给另一侧添加种子。
- 真实苹果的种子数量、饱满程度以及横截面外观会随果实和切割位置变化。模型中“每室 2 颗”是演示设置，不应当作固定自然规律。

## 代码结构

- `src/apple.ts`：参数曲面、上下半壳、封闭切面、程序纹理、三维种子、果梗、叶片和演示刀。
- `src/main.ts`：Three.js 场景、灯光和阴影、OrbitControls、动画与交互状态、射线拾取、视角切换、资源释放。
- `src/style.css`：中文界面、响应式布局。
- `tests/apple.spec.ts`：浏览器交互、移动端、减少动画、动画中断与切面几何一致性检查。

### 建模方法

用极角 `theta` 和方位角 `phi` 构造带轻微五瓣起伏的苹果表面；赤道是 `theta = π/2`、`y = 0`。上下外壳共享同一圈赤道顶点，截面沿该边界建立三角扇封口，两个截面的法线方向相反，因此并非只显示一个空心红色壳。

横截面由浅色程序纹理、五瓣果心和种子室组成。每颗种子先生成完整的竖向锥化椭球，再对其三角形逐个执行半空间裁剪，保留 `y >= 0` 或 `y <= 0` 的片段；两个封口用同一切割轮廓，法线相反。种子截面外圈为棕色种皮，内芯为浅色。切面与果肉通过深度偏移避免闪烁。透视时隐藏截面，两个片段在原位组成同一颗完整种子。刀具动画只演示预设横切，不支持任意切割。

## 测试

```bash
npx playwright install chromium
npm test
```

测试使用独立的 `5188` 端口（已占用则失败）；截图输出在 `test-results/`。在没有硬件 GPU 的测试环境中，Playwright 使用 Chromium 软件 WebGL。

## 在 SHOW 仓库内维护

本目录现在是苹果演示唯一维护源头，不再修改仓库外旧工程或手工修改 `projects/apple-explorer/`。

- 本目录 `npm run build` 只生成临时 `dist/`，不会同步线上目录。
- 仓库根目录 `npm run build` 会构建并同步到 `projects/apple-explorer/`。
- 仓库根目录 `npm run verify` 执行同步、完整测试和产物一致性检查。
- `public/` 存放随发布包输出的许可证与部署说明。
- 源 HTML 保留返回入口，导航 CSS 和 favicon 来自根目录共享资源，构建后资源引用使用相对路径。
- Vite 开发服务只预览苹果项目，完整站点导航要用根目录 `npm start` 验证。
- 提交时同时提交本目录源码和生成的发布目录；测试截图、依赖和本目录 dist 不提交。

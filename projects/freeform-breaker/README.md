# 自由反弹 / Freeform Breaker

零依赖 Canvas 打砖块游戏，无需安装、构建或联网。

## 开始玩

直接用浏览器打开本目录的 `index.html`。也可以在此目录运行：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4174`。

## 操作与规则

- 鼠标或触屏：挡板在整个场地上下左右移动，不限底部。挡板可穿过砖块，但球碰砖块才产生伤害。
- WASD / 方向键：键盘移动；空格：开始、继续、暂停；Esc：暂停。
- 挡板上下两面都反弹；击球位置和横向挥动影响角度。挡板有高速移动上限，避免瞬移穿球。
- 上、左、右边界反弹；球完全掉出底部才消失。所有球消失才扣一命，初始三命。
- 5 种模板叠加随机缺口、血量和道具；砖块血量始终为 1–100，前期主要为低血量。数字为剩余血量，颜色为硬度，受损时显示短血条与裂纹。
- 初始伤害 1，每两关 +1；剩余不超过 3 块时额外 +2，减少残局耗时。高血量砖块不一定需要等量击中次数，因为伤害会成长。
- 击碎带道具标记的砖块后掉落补给，挡板接到才生效。
- 一球变三：从一颗现有球额外分裂两颗，总计最多 9 球。
- 加长：基础长度 +30%，18 秒；缩短：基础长度 −30%，10 秒。正负效果互相替换；同类道具刷新时间，不累乘。
- 新增砖块：随机空位出现至多 5 块、1–3 血的高分砖；预告 1.25 秒后生成。如与球或挡板重叠，等待位置安全后再生成。新增砖块不掉道具。
- 3.5 秒内连续击碎累计连击，每 4 连击提升得分倍率，最多 5 倍。过关奖励为关卡数 ×300。
- 失去生命保留砖块进度，但清除补给、待生成砖块和临时效果。每关重新生成布局，保留得分与剩余生命。
- 切换窗口自动暂停；音效默认关闭，可在右上角开启。最高分保存在当前浏览器本地，无网络传输。
- 重新开始需二次点击确认（进行中或暂停时）。

## 实现与验证

- `engine.js`：与页面无关的游戏引擎，480Hz 最大物理步长，球速上限、双面碰撞、多球与关卡状态。
- `game.js`：Canvas 绘制、输入、音效、本地纪录、界面状态。
- `style.css` / `index.html`：响应式界面，支持直接从本地文件打开。
- 在仓库根目录运行 `node --test tests/engine.test.cjs`：Node 内置引擎测试，无第三方依赖。
- 在仓库根目录运行 `npm run test:site`：引擎测试与站点浏览器回归测试。
- URL 添加 `?test=1` 可显式暴露 `window.__game` 供本地浏览器回归验证；正常模式不暴露。

若直接打开文件时浏览器不允许本地存储，游戏仍可游玩，只是不保证纪录持久化。
